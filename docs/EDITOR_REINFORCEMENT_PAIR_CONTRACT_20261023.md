# 현재 전투의 단일 아군 증원 계약

2026-10-23. 이 문서는 좌표 조건 뒤에 새 파일럿 한 명과 일반 기체 한 대를
현재 전투에 생성하는 최소 형식을 정리한다. 저장소의 pure builder는 이 형식을
생성하며 callback 설치, 맵 인증, 공간 검사, 한 번만 실행하는 권한은 부여하지
않는다. 원래 스토리의 미래 합류를 이동하거나 중복 억제하는 기능과도 구별한다.

## 파일럿 보유 조회와 삭제 제한
