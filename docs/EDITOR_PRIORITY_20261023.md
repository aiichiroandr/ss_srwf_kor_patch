# 쉬운 과제 우선 실행 순서

사용자의 2026-10-23 지시에 따라 재정렬한다. 전체 목표를 축소하지 않는다.
복잡한 완결편 신규 dispatcher는 현재 비활성 상태에서 뒤로 옮긴다.

| 순서 | 작업 | 완료 기준 |
|---|---|---|
| 1 | 기존 테스트 실패의 현 상태 확인 및 낡은 fixture/실제 결함 수정 | 실패 원인별 수정, 관련 검사 통과. 승인 범위 완화 금지 |
| 2 | 이미 구현된 기능의 누락·잘못된 안내 정리 | 실제 UI/저장 동작과 안내 일치. 미지원 기능을 지원으로 표시하지 않음 |
| 3 | 미리보기 개별 문제: 기본 파일럿·음악·반격 종료·문제 무기 | 재현 가능한 문제부터 수정하고 해당 재생 경로 확인 |
| 4 | 무기 음성 지정 가능 범위 확인 및 가능한 편집 연결 | 실제 데이터 필드가 확인되는 범위만 UI→JSON→저장→재열기 |
| 5 | 기존 지원 맵의 증원과 추가 대사 연결 | 등장 조건과 대사를 한 거래로 저장/복원. 기존 이벤트 보존 |
| 6 | 기체만 입수하는 이벤트 | 확인된 명령 기반 생성·중복 정책·저장·재열기 |
| 7 | 완결편 신규 증원 | Final9 실행 코드·UI·저장·재열기 연결. 원본 공간 보존 |
| 8 | F/완결편 지원 맵 확대 | 맵별 원래 생성/삭제/할당 조건을 보존하며 지원 확대 |
| 9 | 조기 합류 후 원래 이야기 중복 처리 및 범용 시나리오 편집 | 분기·재합류·삭제를 포함한 공통 정책과 편집 연결 |
| 10 | 타임라인 정확한 폭발/모션 분리·피해 계산 확대 | 실제 runtime 근거가 있는 이벤트/계산으로 연결 |

외부 AI 무인증 자동 호출은 사용할 공식 경로가 없어 별도 의존성 항목이다.
α 등급·천지인·크리스 조사·세이브 파츠 강제 확장은 제외를 유지한다.
얼굴 변경 시 이름 초기화 ROM 수정은 후속 패치 보류를 유지한다.
배포는 별도 승인 사항이다. 콜드부트·대형 산출물을 기본 검증으로 만들지 않는다.

각 항목은 검사 수가 아니라 실제 기능 완료 여부로 보고한다. 예상 난이도가
틀렸다면 확인된 원인을 기록하고 다음 독립 과제를 먼저 처리한다.
