F 마이너 v0.5

1. 유닛·무기 일괄 개조 기능 추가

  • 좌우 방향키로 원하는 개조 단계를 정하고 한 번에 적용할 수 있습니다.
  • 유닛은 여러 항목을 함께 선택할 수 있으며, 선택한 단계는 초록 칸으로 표시됩니다.
  • 선택한 단계에 맞춰 예상 능력치와 비용을 표시합니다.

2. 전투장면 전환 조작

  • 전투장면 ON/OFF 단축키를 스피드업(커서 가속) 버튼 + START 조합으로 변경했습니다.
  • 공격·반격 선택 화면에서는 R 버튼으로도 전환할 수 있습니다.

3. 전투장면 건너뛰기 기능 추가

  • 전투장면 도중 START를 단독으로 누르면 남은 연출을 건너뛰고 맵에서 전투 결과를 확인할 수 있습니다.

4. 전투 BGM 선택 기능 추가

  • 공격·반격 선택 화면에서 L 버튼으로 파일럿 계열에 배정된 곡을 순환합니다.
  • 선택 화면에 곡 제목과 전투장면 ON/OFF 상태를 표시합니다.
  • 에바의 기본 전투곡을 「잔혹한 천사의 테제」로 변경했습니다.
  • 선택한 곡은 세이브에 저장되지 않습니다.

5. 메뉴와 글자 표시 개선

  • 적용 중인 정신기 이름을 알아보기 쉽게 표시하고, 개수에 따라 정보창이 최대 3줄까지 늘어납니다.
  • 개조창의 진입·선택 표시와 비용 정렬을 개선했습니다.
  • 지형 정보창의 응답, 일부 이름·용어, 엔딩 크레딧의 한글 표시를 개선했습니다.

6. 이용 시 참고사항

  • 버전 변경 시 에뮬레이터의 상태저장 대신, 게임 내에서 저장한 본체 RAM·카트리지 RAM 세이브를 옮겨 사용해 주세요.
  • 아직 보완할 부분이 있으며, 발견되지 않은 게임 멈춤이나 글자 깨짐이 발생할 수 있습니다.
  • 원본이나 이전 패치에는 없던 오류가 이번 버전에 나타날 수도 있습니다.
