# 로컬 에디터 진행 목표

2026-10-15 사용자 요청으로 기존 PixiJS 전투 플레이어·무기 연출 편집 목표에
아래 액플 사례의 편집 기능을 추가한다. 기존 목표의 대사·음성·HP/EN·피해·
방어·격추·음향·미지원 연출 개선과 전체 지원 범위 조사는 유지한다.
이 문서는 완료·배포 승인 또는 게임 실행 증거가 아니다.

## 추가 완료 조건

1. 파일럿·기체 지형 적응을 구분하여 표시·편집한다. 코우지, 효마,
   마사키, 신고, 쇼우, 마장기신 파일럿, 에바 파일럿의 우주 A 변경을
   지원한다. 사용자 글의 nibble5(α 기호)는 일반 A와 별개로 조사한다.
   파일럿5+기체B의 합성값·화면 표기·전투 계산을 구분하고, 확인된
   동작을 도움말과 편집 허용 범위에 반영한다. 값5를 무조건 강한 A로
   간주하거나 모든 초과값을 안전하다고 허용하지 않는다.
2. 무기의 격투/사격, 이동 후 공격(P), 베어내기 당하는 속성을
   직접 편집한다. 기체의 베어내기 능력과 다른 항목임을 UI에서 명확히 한다.
   기존 공격력·사거리·EN·필요 기력·잔탄·크리티컬 수치와 함께 저장한다.
3. 빌바인 하이퍼 오라베기: 베어내기 대상 해제, 크리티컬 보정20,
   필요 기력120 사례를 구현·검증한다. 원시 nibble과 화면 보정%를 혼동하지 않는다.
4. 사이바스터 아카식버스터: 격투, 최대 사거리3, EN30.
   코스모노바: 격투, P, 필요 기력130, 잔탄2 사례를 지원한다.
5. 사이바스터 난무의 태도: 디스커터 기반 변경 또는 별도 신규 무기로
   만들 수 있게 한다. 이름, 전투대사 선택, 폭렬 갓슬래시 연출 연결,
   크리티컬 보정20, 기력130, EN60, 공격력5000 사례를 포함한다.
   무기 이름과 대사/음성 식별자는 별개다. 음성 새 합성은 요청 범위가 아니다.
6. 에바0호기 롱기누스의 창·포지트론 스나이퍼 라이플을 무장에
   연결하고, 창의 궁그닐 연출·필요 기력110 사례를 지원한다.
   추가·교체와 슬롯/편집 공간 제한을 명시하고 다른 무장을 훼손하지 않는다.
7. 각 변경은 원본 읽기→이름/레코드 연결→UI→미리보기→변경 목록→
   원복→편집값 저장/불러오기→BIN 전체 출력→해시 인증 재불러오기와
   재파싱까지 검증한다. F/완결편 공통 기능은 양쪽을 검사한다.
   완결편 전용 무장을 F에도 있다고 가정하지 않는다.

## 입력 및 검증 경계

- 사용자가 붙여준 글은 일부 코드·설명이 OCR로 깨져 있다. 명확한 설명과
  실제 원본 레코드를 대조하고, 불명확한 수치/코드는 추정 적용하지 않는다.
- 액플 RAM 주소는 디스크 offset이 아니다. 코드 직접 입력/CEP 변환기는
  현재 추가 목표가 아니며, 동일한 편집 결과를 에디터 항목으로 제공한다.
- 디스크는 사용자가 제공한 로컬 파일만 처리한다. 게임/에뮬레이터 실행,
  원격 배포, ROM·추출 게임 자료의 저장소 추가는 하지 않는다.
- 활성 목표는 미완료다. 부분적인 해석/재생/테스트 통과를 전 무장 완료로
  보고하지 않는다. 제어 신호·음향 자료 등 미해결 의존성은 숨기지 않는다.

## 우선순위

효과 조합과 무기 속성 세 비트, 파일럿 지형5는 최신 승인 한글패치 입력에서
JSON·전체 BIN 출력·개인 편집본 재인증까지 확인했다. 원본 언어 유지 입력의
새 무기 속성 왕복은 별도로 마무리한다. 전투대사 선택의 실제 원문·음성
미리보기와 무기 설정 저장은 양쪽 웹에 연결했고, 최신 승인 한글패치 입력의
JSON·전체 BIN 재인증까지 확인했다. 난무의 태도 신규 생성과 롱기누스 연출
연결은 두 게임 데이터 왕복 및 완결편 웹 생성·재생까지 확인했다. 에바0호기
기존 무장의 등장 조건도 두 게임 JSON·전체 BIN 재인증과 연출 프로젝트
동시 저장까지 확인했다. F/완결편 웹에서 조건 변경·원복을 확인했고,
최신 완결편320px에서는 변경 목록 이동과 행 높이58px도 실측했다.
F 원본 언어 입력에서도 새 속성·대사·무장 조건의 BIN 재인증을 확인했고,
원본 명칭 decoder와 편집본 재불러오기도 수정했다. 완결편 원본은 미검증이다.
원본 F 신규 이름은 원본 글꼴·중복 문자열 공유 방식으로 JSON 실제 다운로드/재불러오기·전체 BIN 재인증·부분 삭제·원복까지 확인했다. 이름당 연속 공간 제한이 남고 완결편 원본은 미검증이다.
다음에는 미지원 연출·음향 의존성과 원본 언어 이름 공간의 한계,
효과 조합의 웹 미리보기 범위를 계속 검증한다. 특정 예시 하나의 재생만으로 전체 목표를 끝내지 않는다.
진행/검증 근거는 `EDITOR_WEAPON_AUTHORING_PROGRESS.md`에 누적한다.
