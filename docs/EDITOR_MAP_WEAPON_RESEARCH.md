# MAP 병기의 웹 연출 조사 — 2026-10-15

상태는 미완료다. 일반 전투 플레이어가 공용 기본 연출을 MAP 병기의 전용 연출로 표시하지 않도록 차단한 상태이며, 아래 정적 근거만으로 MAP 연출 재생 완료를 주장하지 않는다. 게임·에뮬레이터는 실행하지 않았다.

## 기준 원본

- F 승인 v0.5 a 실행 파일 SHA-256: `308fe51501cd70091fe1a9983101d6cd98b9fdc7d8857e4bac9e2bff3e9974f1`.
- F 완결편 승인 v0.3 c 실행 파일 SHA-256: `2b17a510e9eb4758ada3aa954577222b848d15b573c56f63610e1cdc1d3320c0`.
- 실행 파일 좌표 기준 주소: `06004000`. 아래 주소는 디스크 raw offset이나 TSR 상대 주소가 아니다.

## 무기 속성에서 별도 처리로 이어지는 근거

원본 무기 root29 레코드의 첫 BE16 워드에서 bit15는 MAP 속성이고 bit13:8은 패턴 번호다. 폭도색의 워드는 양 게임 모두 `8910`, 패턴 번호는9다. 일반 전투 애니메이션 선택값은0이다. TSRViewer의 읽기와 실제 실행 파일의 아래 소비 경로를 구분해서 기록한다.

| 단계 | F | F 완결편 | 확인한 동작 |
| --- | --- | --- | --- |
| 무기 속성 복사 | `0602DE3E..0602DE62` | 대응 로더 `06031B7C` 내부 | 첫 속성 byte의 상위2bit·하위6bit를 무기 작업 행+50에 보존 |
| 작업 속성 소비 | `0604B45E..0604B46E` | `06050E02..06050E10` | 작업 행+50의 하위6bit로 byte 유형 표 조회 |
| 유형 표 포인터 literal | `0604B648` | `06051014` | 각각 `060B4F88`, `060BB730`을 가리킴 |
| MAP 유형 분기 | `0604B48E..0604B498` | `06050E38..06050E42` | 작업 속성의 상위2bit 값2를 구분 |

폭도색의 패턴9는 양쪽 유형 표에서2로 연결된다. 다만 이 소비 함수에는 좌표 비교와 참/거짓 반환 경로가 있으므로 이 표를 **스프라이트·애니메이션 번호 표로 해석하지 않는다**. 표의 유형별 영역 규칙과 MAP 연출의 그림·대기·음원을 연결하는 과정은 아직 끝나지 않았다. F에서 유형2 분기의 첫 목적지는 `0604B516`이다.

## 별도의 EFFECT 그림 적재 경로

원본 EFFECT.BIN은 파일 resource17이다. F `060732D4`, 완결편 `06079E54`의 핸들러가 resource17과 피연산자의 선택값으로 직접 파일 적재 함수를 호출한다. F 적재 함수는 `0600B818`, 완결편은 `0600BB14`다. F와 완결편의 피연산자 배치는 같다고 가정하지 않는다. F는+1의 flag/선택값과+2, 완결편은+1의 flag와+2/+3을 읽는 분기가 있다.

이 핸들러는 각각 subdispatch 표 `060B5420` / `060BBC44`의 index20에 등록돼 있다. 상위 dispatcher는 F `06070CA4`, 완결편 `0607769C`이며 VM의 CTX 포인터가 가리키는 첫 byte를 unsigned index로 읽는다. 이 dispatcher는 main 함수 표의 index155와 별도의 함수 표 index59에도 참조된다.

여기까지 확인한 것은 **효과 그림 적재 명령의 경로**다. 폭도색 패턴9가 어떤 프로그램을 선택해서 이 명령에 도달하는지는 아직 입증하지 않았다. 파일 이름이나 그림이 그럴듯하다는 이유로 폭도색에 매핑하지 않는다.

## 다음 최소 조사

가설: MAP 속성의 패턴 번호가 별도 전장 연출 프로그램을 선택한다.

관찰: 패턴→유형 표와 별도 EFFECT 적재 핸들러는 확인됐지만 두 경로 사이의 프로그램 선택 연결은 확인되지 않았다.

반증: 유형2의 첫 분기는 좌표 판정이므로 그 표를 연출 번호로 사용할 수 없다. `mov #17,r5` 검색도 TSR root17 조회와 혼동되므로 resource17 적재 근거로 사용하지 않는다.

다음 최소 probe: MAP 공격을 구성하는 원본 호출자가 어떤 공통 프로그램을 선택하는지 확인하고, 그 프로그램의 인코딩 경계에서 subdispatch index20에 전달되는 피연산자를 추적한다. 그 연결을 찾은 뒤 기존 로컬 그림 디코더·Pixi 타임라인·음원 준비 경로를 재사용한다.
