# ALICE SP 실제 실행 검증 — 2026-11-13

현재 개인 검수용 F v0.5a 및 F완결편 v0.3c의 Rev1/ALICE 동승 출력을 실제 Mednafen으로 실행했다. 이번 검증에서 게임의 동승 코드, 파일럿 정의와 저장 형식을 바꾸지 않았다. 공개 배포나 새로운 릴리스 승인을 뜻하지 않는다.

## 정신기 소비

S와 Ex-S를 동시에 배치하고 각 인간 주파일럿의 ALICE로 **집중(15 SP)**을 실제 메뉴에서 사용했다. #399는 공통 파일럿 정의이며, 아래 행 번호는 서로 다른 저장 인스턴스다.

|게임 / 사용 기체|ALICE 행|사용 전 → 후|다른 ALICE 전 → 후|
|---|---:|---:|---:|
|F / Ex-S|15|123 → 108|123 → 123|
|F / S|14|123 → 108|108 → 108|
|완결편 / S|72|101 → 86|101 → 101|
|완결편 / Ex-S|73|101 → 86|86 → 86|

네 경우 모두 선택한 행의 SP16만 15 줄었으며, 나머지 127개 파일럿 SP 워드는 모두 같았다. 원본 소비 함수의 실제 write watch도 같은 주소와 전후 값을 기록했다. F의 두 SP 주소는 `0x20201552`와 `0x2020155E`, 완결편은 `0x2020180A`와 `0x20201816`이었다. 각 주소는 해당 표본의 파일럿 표 기준이며 다른 저장본의 고정 주소로 사용하지 않는다.

이번 표본은 기존의 **부대 배치·레벨을 준비한 전투 저장본**이다. 컨테이너 변환 시 게임 저장 payload 전체의 동일성과 체크섬을 확인했고, 게임이 ALICE 두 행을 생성했다. 사용·변형·저장·재시작 중에는 ROM/RAM이나 게임 저장 내용을 수정하지 않았다. 자연 진행으로 해당 부대를 배치했다는 증거 또는 통상 난이도 검증으로 확대하지 않는다. 웹에서 준비한 Lv1/SP25 ALICE의 탑승·일반 저장 검증은 [이전 후속 검증](ALICE_SUBPILOT_FOLLOWUP.md)의 별도 표본이다.

## 변형 및 저장

- F S건담을 게임의 변형 명령으로 G크루저(348 → 349)로 바꿨다. 같은 기체 칸 9를 사용했고 HP 4000, 두 ALICE 및 모든 파일럿 행/SP가 그대로였다.
- 완결편 Ex-S를 G크루저(432 → 433)로 바꿨다. 같은 기체 칸 74를 사용했고 HP 5000, 두 ALICE 및 모든 파일럿 행/SP가 그대로였다.
- 양쪽 모두 게임의 중단 저장 메뉴로 실제 저장했다. 체크섬이 정상인 저장 파일을 새 프로필에 복사하고, 복사본의 스테이트를 제거한 뒤 프로세스를 새로 실행해 CONTINUE로 불러왔다. F는 각각 108 SP, 완결편은 각각 86 SP를 유지했다. 모든 활성 파일럿 행과 기체 ID/주파일럿 연결이 저장 전과 같았다. ALICE나 보유 기체가 늘지 않았다.

이 중단 저장은 게임 자체의 기능이다. 웹 세이브 편집기가 `0x3150` 중단 저장 편집을 지원한다는 의미는 아니다. 이번 변형 표본만으로 반대쪽 두 변형 조합 전체를 새로 검증했다고 주장하지 않는다.

## 범위와 증거

SP 소비는 각 ALICE 행에 독립적이다. 다만 현재 ALICE의 저장 연결은 인간 주파일럿의 동승자 체인이다. 인간을 교환할 때 SP가 기체에 영구 귀속된다고 보장하지 않으며, [기존 교환 검증과 설계 한계](ALICE_SUBPILOT_FOLLOWUP.md)를 그대로 적용한다.

완결편의 시나리오 전환 시 회복, 모든 갈아타기 조합, 장기 합류·탈퇴·분기 및 통상 난이도 전체를 이 소비/재로드 결과로 검증했다고 주장하지 않는다. 아래 F 회복용 HP1 보조 표본은 소비·저장 표본과 분리한다.

별도 HP1 보조 표본에서 F Ex-S가 실제 적을 격파한 뒤 그 ALICE 행 15만 레벨 50 → 51이 됐고, S의 행 14는 레벨 50을 유지했다. 두 행 모두 SP 108을 유지했다. 파일럿 정의 #399를 공유해도 레벨 진행은 각 저장 행에 따로 기록됐다. F 레벨 50을 준비한 검사 조건이므로 자연 육성이나 통상 난이도의 검증이 아니다. 완결편의 보조 진행은 3턴 증원 선택까지이며 다음 시나리오 회복을 통과로 기록하지 않았다.

## F 회복·인터미션·다음 맵

F의 별도 HP1 보조 표본에서 실제로 남은 적을 격파하고 1화를 완료했다. 인터미션에서 두 ALICE는 레벨 51, **SP 125/125**로 회복됐다. 실제 파일럿 능력 목록에도 `ALICE — S건담`, `ALICE — Ex-S건담` 두 줄이 표시됐다. 각 상세 화면의 NEXT는 280 / 279로 실제 일반 저장의 두 행과 일치했다.

S의 크루저 형태는 게임이 같은 칸에서 기본 S로 되돌렸다. 클리어 전후 보유 기체는 다섯 기, ALICE는 두 행으로 유지됐으며 기본 S나 크루저가 중복 지급되지 않았다. 이 표본은 **이미 다섯 기를 보유한 배치 저장에서 시작했으므로**, 새 게임에서 0 → 5기 지급하는 초기화 검증으로 대신하지 않는다.

게임이 쓴 `SROBOT_F_01` 일반 인터미션 저장(`0x1600`)의 체크섬, 두 ALICE의 125 SP 및 다섯 보유 기체를 확인했다. 세이브 코어로 읽고 무수정 내보내기한 바이트도 원본과 완전히 같았다. 이 코어 검사는 실제 브라우저 UI 검사와 구분한다.

그 뒤 다음 시나리오 도입부와 전투 맵까지 진입했고, 보유 다섯 기·ALICE 두 행·125 SP가 유지됐다. 해당 맵에서 다섯 기체를 모두 출격시켜 전투했다거나, 두 번째 클리어/다음 인터미션·모든 루트·장기 분기를 완주했다고 주장하지 않는다. 완결편 보조 표본은 3턴 증원 선택까지이며 회복은 미검증이다.
