# 사용 가이드 유지보수

헤더의 **사용 가이드**는 현재 구현된 폴더 열기·언어 선택·편집·편집값 JSON·BIN/CUE 저장을 화면 캡처로 안내한다.
`assets/user-guide.mjs`는 표시 중인 DOM에서 시작 경우와 단계를 읽으며, 앱 상태·파일·편집값을 수정하지 않는다.
창을 열기 전에는 캡처를 요청하지 않는다. 모든 이미지와 스크립트는 같은 사이트에서 제공한다.

## 캡처 범위

- 원본에 한글 패치 적용 / 원본 언어 유지 / 최신 한글 패치본 / 기존 편집본.
- 각 시작 경우에 15페이지: 폴더, 작업 선택, 편집 안내 10개, 편집값 파일, BIN/CUE 생성, BIN/CUE 다운로드.
- 편집 안내는 목록·검색, 수치 변경·되돌리기, 기체 지형, 기체 특수능력, 파일럿 능력·성장, 정신커맨드, 파일럿 특수능력, 무기 수치, 무기 지형, 변경 목록으로 나뉜다. 주제 선택으로 바로 이동할 수 있다.
- 편집 화면에서 가이드를 열면 현재 선택한 기체·파일럿·무기 탭의 설명을 먼저 표시한다.
- 데스크톱과 세로 휴대폰 캡처를 각각 2배 해상도로 제공한다. 화면 폭에 따라 `<picture>`로 선택한다.
- 아직 구현되지 않은 구버전 업데이트·편집값 이전 시안은 포함하지 않는다.
- 현재 HTML/CSS에 만든 예시 레코드만 넣어 캡처한다. 사용자 디스크나 추출한 기체·파일럿 그림을 읽지 않는다.
- 상세 편집 캡처는 조작 대상 패널을 중심으로 잘라 숫자·선택·추가·삭제 버튼을 읽을 수 있게 한다.
- 캡처는 사용법 설명용이며 실제 게임 수치, 바이너리 검사 또는 내보내기 성공의 증거가 아니다.

## 화면 변경 후 갱신

로컬 사이트를 띄운 뒤 다음을 실행한다. 출력 폴더는 저장소 밖에 두고 실제 화면과 캡처를 대조한다.

```sh
node scripts/user-guide-capture.cjs --url=http://127.0.0.1:8811/ --out=/private/tmp/srwf-user-guide-captures --playwright=/absolute/path/to/playwright --browser=/absolute/path/to/browser
```

검토한 PNG만 `assets/user-guide/`에 복사하고 `scripts/verify_repo.py`의 `PUBLIC_ASSET_ALLOWLIST`에 해당 파일의 SHA-256을 갱신한다.
`capture-report.json`은 공개 에셋에 포함하지 않는다. UI 문구는 `assets/user-guide.mjs`, 배치는 `assets/editor-runtime.css`에서 수정한다.
가이드 창의 높이는 실제 캡처 비율과 안내 영역을 측정해 정하고 화면 높이로 제한한다.
