# 로컬 게임 데이터 에디터

정적 패치 사이트에는 세가 새턴판 **슈퍼로봇대전 F**와 **슈퍼로봇대전 F 완결편**의
승인 패치 이미지를 편집하는 브라우저 에디터가 포함되어 있습니다. 파일과 수정 데이터는
사용자의 기기 안에서 처리합니다. 웹사이트로 전송하지 않습니다.

## 사용 방법

1. 패치 사이트에서 게임과 편집할 승인 버전을 선택합니다.
2. 패치 노트 옆의 `스탯 에디터 열기`를 눌러 에디터 화면으로 이동한 뒤, 저장해 둔 승인 패치
   결과를 `승인 패치 BIN 선택`으로 고릅니다. 원본 폴더를 고른 경우에는 검증된 패치 결과가
   자동으로 에디터에 열립니다(아래 원본 선택 후 편집 흐름).
3. BIN 전체 크기와 SHA-256이 선택한 승인 버전과 일치하면 기체, 파일럿, 무기 탭이 열립니다.
   원본 선택 흐름에서 패처가 방금 만든 결과는 패치 단계에서 이미 전체 검증한 불변 파일을
   재사용합니다. 직접 선택한 BIN은 에디터에서 전체 해시를 확인합니다. 확인하는 동안 진행률과
   `중단` 버튼, 오류는 에디터 화면에 표시됩니다.
4. 기체·파일럿·무기 탭에서 **한글 이름과 번호**로 항목을 찾습니다. 기체 탭은 선택한 기체의 게임 스프라이트를, 파일럿 탭은 얼굴 이미지를 함께 보여 줍니다. 무기 탭은 각 무기의 한글 이름과 번호를 표시합니다.
5. 선택한 항목의 수치를 수정하고 `개인 수정 BIN/CUE 만들기`를 누릅니다.
6. 내려받은 BIN과 CUE를 같은 폴더에 두고, 에뮬레이터에서 개인 수정 이미지를 엽니다.

원본 ROM이나 임의로 수정한 이미지, 다른 게임·버전의 패치 결과는 승인 이미지 검사에서
거부됩니다. 다른 버전을 편집하려면 `게임·패치 설정`으로 돌아가 그 버전을 먼저 선택해야
합니다. 편집 세션이 있으면 패처의 같은 버튼이 `에디터로 돌아가기`로 바뀝니다. 에디터
화면에도 비공식 팬 프로젝트이며 게임 원본을 포함하지 않는다는 안내가 표시됩니다.

수정한 값이 있는 상태에서 게임·버전·폰트를 바꾸거나 원본 폴더 또는 BIN을 다시 고르면,
수정값을 버릴지 먼저 확인합니다. 수정본을 만드는 동안에는 편집 화면이 잠기며, 수정본을
만든 뒤 값을 다시 바꾸면 이전 다운로드 링크는 지워집니다.

## 편집할 수 있는 값

- **기체:** HP, EN, 장갑, 이동력, 운동성, 한계 반응, 지상·바다·공중·우주 적응도
- **파일럿:** 격투·사격·명중·기량·회피·방어, 정신 포인트, 초기 경험치, 성장 보정,
  지상·바다·공중·우주 적응도
- **무기:** 공격력, 명중·크리티컬 보정, 최소·최대 사거리, 지형 적응 수치, 소비 EN

파일럿 화면에는 파일럿별 정신커맨드와 습득 레벨도 표시합니다. 이 정보는 TSRViewer가
사용하던 파일럿 기록의 커맨드 ID·레벨 쌍과 해당 승인 이미지의 이름표에서 읽습니다.
쓰기 경로는 검증되지 않아 보기 전용입니다. 정신커맨드가 여섯 개 미만인 기록에서는 첫
특수능력 ID가 정신커맨드와 특수능력의 경계 역할을 하므로, 첫 슬롯에는 ID 48 이상의
특수능력만 고를 수 있습니다. 원작 MC7 파일럿 화면에 표시되는 정신 포인트는
파일럿 수치에 포함되며, 개별 정신커맨드의 소비 SP는 파일럿 기록에 들어 있지 않습니다.

표시되는 숫자는 게임 데이터의 원시값입니다. 성장 보정과 지형 적응은 화면에 표시되는
등급 문자 대신 숫자로 편집합니다.

기체 스프라이트와 파일럿 얼굴은 승인 BIN 안의 게임 이미지 파일(`C_ROBOT.BIN`,
`FACE.BIN`)에서 선택한 항목 번호로 읽어 브라우저 화면에 표시합니다. 이미지 파일은 세션마다
한 번만 읽어 기기 메모리에 보관합니다. 이 파일을 찾지 못해도 에디터는 열리며 이미지 없이
표시합니다. 이 이미지를 웹사이트에 따로 싣거나 전송하지 않습니다.

## 제한 사항

에디터는 실행 중인 게임의 메모리에 접근하지 않습니다. 승인 패치 BIN 안의 `TSR.BIN`을
정적으로 수정해 개인용 BIN/CUE를 만듭니다. 수정값을 게임에서 사용하려면 새 이미지를
에뮬레이터에 다시 열어야 합니다.

새 `TSR.BIN`이 원본 이미지의 ISO 파일 크기보다 커지면 에디터는 저장을 중단합니다.
디스크 안에서 파일을 옮기거나 이미지 용량을 늘리지 않습니다. 섹터 형식·체크섬·게임
데이터 표 구조를 확인할 수 없는 경우도 저장하지 않습니다.

개인 수정 BIN/CUE는 공개 승인 릴리스나 배포 패치가 아닙니다. 사이트는 ROM, 완성 이미지,
사용자 수정본을 받거나 보관하지 않습니다.

### 원본 선택 후 편집 흐름 (2026-09-23)

원본 폴더를 선택하면 PREPARE_SOURCE 후 브라우저 내부에서 승인 패치 결과를 구성하고 원본/결과 해시를 검증한다. 중간 결과는 저장하지 않고 에디터 입력으로 전달하며, 데이터를 읽는 동안 에디터 화면으로 전환한다. 사용자는 수치를 편집한 뒤 `패치 실행 · 수정값 반영`을 눌러 최종 개인용 BIN/CUE를 다운로드한다. 원본·게임·릴리스 변경은 편집 세션을 초기화한다. 기존 승인 BIN 직접 열기도 유지한다.

에디터 데이터 읽기가 실패하거나 중단되면 패처에도 같은 오류를 표시하고, 패치 버튼은 수정값 없이 일반 한글 패치 BIN/CUE를 만드는 동작으로 돌아간다.

수정 TSR이 커진 경우 이미 할당된 마지막 ISO 섹터의 0으로 채워진 padding까지만 사용할 수 있다. 다음 섹터로 확장하지 않으며, padding 검증·압축 roundtrip·EDC/ECC 검증·최종 전체 해시 후에만 결과를 제공한다. 개인 수정본 해시는 승인 릴리스의 해시와 별도로 표시한다.
