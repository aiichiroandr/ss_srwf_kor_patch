수정 · 세이브 인계

F → 완결편에서 연동 기체가 다른 기체로 바뀌던 문제

같은 기체라도 두 게임의 기체 번호가 달라 그대로 넘기면 다른 기체로 인식되는 문제가 있었습니다. F와 완결편의 연동 BIN을 대조해 선택한 F 클리어 슬롯의 인계용 사본을 만드는 도구를 추가했습니다. 원본 저장은 건드리지 않습니다.

사용 위치: 세이브 에디터 → F → 완결편 세이브 승계. 사용 가이드에서도 열 수 있습니다.
