# F 슈퍼계 단쿠가 도입 정지 수정 (2026-11-16)

브라우저 에디터의 F 제4차 기체 연동 출력 경로 수정이다. 기본 한글 패치의
릴리즈·배포 파일·승인 상태는 변경하지 않는다.

## 원인과 수정

F의 시나리오 실행 공간은 56바이트 루트 표를 포함해 32,768바이트다.
슈퍼계 「합체!! 초수기신 단쿠가」(선택자 65, 물리 본문 45)에 기체
이탈 보호를 추가한 공개 출력은 33,014바이트로 이 공간을 넘었다.
도입 이후 보호 코드가 덮여 실행이 멈추는 현상을 실제 실행에서 확인했다.
ALICE 설정이나 세이브에 기체를 추가했는지 여부만의 문제는 아니었다.

14개 보호 지점의 기능과 원래 시나리오는 유지한다. 같은 대상의 보호
처리를 8개 공통 루틴으로 공유하여 본문을 32,730바이트로 줄였다.
기존 출력의 정확한 구형 형식은 읽고 정규화하며, 같은 옵션으로 다시
내보내도 수정 형식으로 이행한다. 모든 출력 처리 뒤에는 인증된 F 기반
(일본어 원본 포함)의 시나리오 전체에 실행 공간 검사를 적용한다.
공간을 초과하면 결과 파일을 제공하지 않는다.

웹사이트 갱신만으로 이미 내려받은 ROM이 바뀌지는 않는다. 기존 편집
ROM은 갱신된 에디터로 불러와 다시 내보내야 한다. 원본과 세이브는
별도로 보관한다. 이 변경은 처음부터 새 게임을 시작하라는 요구가 아니다.

## 검증 범위

- F v0.5 a/b/c: 전체 이미지 해시 인증, 시나리오 52개 물리 본문·74개
  선택자·728개 루트 포인터 검사. 세 글꼴의 시나리오 파일은 동일하다.
- 306개 보호 지점 및 첫 승리 추가 프로그램의 분기·명령 경계·공간 검사.
  공개 출력의 초과는 선택자 65 한 곳이었으며 수정 출력에는 없다.
- 구형 입력의 동일 옵션 이행, 새 출력 재열기와 재출력 멱등성, 기존
  기체 수치 보존, 손상된 명령·기록 거부, 최종 용량 초과 차단 시험.
- 실제 F 슈퍼계 도입·전투 진입, 시험용 승리 조건으로 원래 종료 이벤트,
  파트너 생성·게임 내 저장·다음 시나리오 진입을 확인했다. 시험 승리는
  종료 이벤트를 건너뛰는 방식이 아니며, 일반 전투 전체 플레이와 다르다.
- 공통 루틴의 호출 깊이 복귀를 실제 실행에서 관찰했다. 모든 경로의
  보호 분기를 장기 플레이로 확인했다는 의미는 아니다.

전체 시나리오 정적 검사는 전 시나리오 플레이 완료를 뜻하지 않는다.
사용자 ROM·세이브·실행 파일·게임 데이터는 저장소에 포함하지 않는다.
