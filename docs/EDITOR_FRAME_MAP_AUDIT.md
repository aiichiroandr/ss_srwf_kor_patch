# 로컬 프레임·배치 표시 검수 (2026-10-12)

## 변경

F 초기 스크립트의 C4.15는 네이티브 선택자가 0..7로 한정된 8개 자기 상대
분기다. 08의 4바이트 조건 분기는 op+2의 signed BE16 셀 기준으로 읽는다.
두 명령을 읽기 전용 해석기에 추가했다. 피연산자 내부 진입·본문 밖 목적지는
허용하지 않는다. 기존 쓰기 마스크와 승인 이미지 검증은 확대하지 않는다.

맵 연결을 확정하지 못한 고정 기체의 원본 x/y는 시나리오 기본 맵에 테두리
표식으로 표시하고 ‘기본 맵 기준 좌표’라고 명시한다. 런타임 편성 참조나
출격 좌표를 추정하여 배치하지 않는다. 원래 mapIndex와 편집 권한은 그대로다.
공통 호출 뒤의 실제 맵·등장 시점이 확인됐다고 주장하지 않는다.

공격 프레임 보기는 전체 E_SPR 묶음을 열거하지 않고, 검증된 main/actor
명령 경로가 선택한 subimage만 읽는다. 동일 actor/sequence의 프레임을
0.25초 간격으로 자동 반복하며 일시정지할 수 있다. 이는 원본 프로그램의
실제 참조 프레임 보기이며 게임의 시간·이동·동시 트랙·전체 전투 합성 재현은
아니다. 미확인 명령 이후의 프레임은 추측하지 않는다.

## 실제 데이터 조사

F v0.5 a 및 완결편 v0.3 c에서 소유 기체가 확인된 편집 가능 무기 각각
1,190개와 1,279개를 대표 소유 기체로 읽었다. 조회 오류는 0개였고, 실제
참조 프레임이 확인된 무기는 1,079개와 1,177개였다. 나머지 213개는 미확인
경로·자료 없음 등의 상태로 유지한다. 모든 소유 기체·분기·동시 트랙 검증으로
확대하지 않는다. 빔사벨은 전체 그림 묶음 대신 실제 참조 7개만 읽었고,
첫 actor 동작의 3개 프레임 반복을 브라우저에서 확인했다.

시나리오 본문 F 52개·완결편 103개, 배치 1,737개·3,105개를 조사했다.
해석 중단 경계가 있는 본문은 36개·67개다. 이 항목들은 완전 해석 완료로
표시하지 않는다. 화면에서 선택 가능한 F 52개·완결편 98개를 데스크톱
1440×1000 및 모바일 세로 390×844로 직접 선택했다. 총 300회 선택에서
페이지 오류·가로 넘침은 없었다. 화면에 선택 항목이 없는 본문 5개를 클릭
검수했다고 주장하지 않는다.

F 제1화 ‘드리우는 암운’의 적군 필터에서 초기 스크립트 11기, 5턴 증원
1기, 추가 적군 스크립트 4기를 각각 선택해 지도 표식·기체 목록·좌표 표시를
확인했다. 사적 BIN·추출 자료·게임 캡처는 저장소에 포함하지 않았다.
