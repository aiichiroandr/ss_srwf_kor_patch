# 롱기누스·난무의 태도 추가 정적 조사

2026-10-23. 승인 완결편 v0.3a에서 기존 ISO/TSR/SCEDATA 해석기를 사용했다. 에뮬레이터·콜드부트·새 공격 시연은 실행하지 않았다. 확인된 데이터와 미확인 연출을 구분한다.

## 롱기누스 #874와 조건 83

- 무기 #874는 이름 `롱기누스의창`, 공격력 5000, 원래 연출 선택자 0이다. 에바 영호기 #232의 5번째 무장에 이미 연결되어 있다. 개조 칸 5, 잔탄 칸 0, 기체 목록의 조건 번호 83, 투자 조건 없음으로 다시 확인했다.
- 일반 시나리오 비트 설정 경로는 실행 파일 주소 `0x060210FC`의 D0 하위 명령 선택 → `0x06021124`(D0.0) → `0x060216D0`이다. 마지막 함수는 `save + 0x534 + (flag >> 3)`에 `1 << (7 - (flag & 7))`을 OR한다.
- SCEDATA의 200 선택자 / 물리 본문 103개 / 전체 압축 해제 1,962,133바이트를 읽었다. **D0.0으로 83을 직접 설정하는 `D0 00 00 53` 바이트열은 전체에서 0건**이었다. 명령·문자열을 포함한 전체를 검색했으므로 이 정확한 직접 명령을 놓친 결과는 아니다.
- D0.3은 범위 루프지만 설정이 아니다. `0x060211DC`에서 루프를 돌며 `0x06021244`의 포인터가 가리키는 `0x06021724`(AND NOT 비트 해제)를 호출한다. 이를 범위 설정으로 해석하는 가설은 폐기했다.
- 위 실행 코드 7개 영역은 재컴파일 원본 v0.3c 자료와 실제 v0.3a의 `/0` 바이트가 일치함을 확인했다. 폰트별 실행 코드 차이를 가정하고 주소를 그대로 옮긴 결과가 아니다.

이 결과로 **일반 시나리오의 직접 비트 설정을 발견하지 못했다**고 말할 수 있다. 다른 명령의 동적 쓰기, 하드코딩된 이벤트, 인계된 저장 상태까지 모두 배제하지 않았으므로 정상 시나리오에서 절대 쓸 수 없다고 단정하지 않는다. 조건 83을 제거하는 것은 기체 무장 목록의 표시/사용 제한을 바꾸는 작업이며, 비어 있는 전용 연출을 생성하는 작업이 아니다.

현재 미리보기는 무장 선택 후의 전투 준비 단계에 무기 #874를 직접 전달한다. 기존 시연에서도 영호기·레이·무기 번호가 전달됐지만 전용 공격 완주는 확인되지 않았다(`WEAPON_PREVIEW.md`). 따라서 조건 83 하나를 켜면 미리보기가 정상화된다고 할 주소 근거는 없다.

## 연출 선택자 0의 의미를 과장하지 않기

실제 무기 1407개 중 양수 공격력이며 선택자 0인 레코드는 65개다. 그중 60개는 헤더 첫 바이트의 상위 bit가 설정되어 있으며, 하이메가캐논·사이플래시·버스터런처 등 잘 알려진 MAP 무기들이 이 군에 포함된다. 이 조사에서는 상위 bit의 실행 코드 의미를 새로 완전히 해독하지 않았으므로 **0 = 미구현**, **0 = MAP**이라는 일반 규칙으로 제품에 넣지 않는다.

상위 bit가 없으면서 양수 공격력 / 선택자 0인 레코드는 다음 5개다.

| 번호 | 현재 이름 | 읽힌 소유 연결 |
|---|---|---|
| 874 | 롱기누스의창 | 영호기 #232 / 조건 83 |
| 936 | 대미사일용유도와이어 | 확인한 기체 무장 목록에는 없음 |
| 1055 | 슈피겔토네이도 | 확인한 기체 무장 목록에는 없음 |
| 1160 | 시즐러홈런 | 확인한 기체 무장 목록에는 없음 |
| 1178 | 검패천왕기염탄 | 확인한 기체 무장 목록에는 없음 |

D_ANIME 안에 0번에 해당하는 데이터가 존재한다는 것과 롱기누스 전용 투척 스크립트라는 것은 다르다. 파일의 데이터가 있다는 사실만으로 이름을 부여하지 않았다. 일반 압축 스트림으로 추정해 임의 해제하거나 주소 기준을 추측한 결과는 근거에서 제외했다. 현재 확정한 실제 실행 경로는 전투 준비 `0x060496DC` → 원본 리소스 로딩/복사 `0x06019F00` → 명령 dispatch `0x06049940`이며, 데이터의 의미를 추가로 이름 붙이지 않는다.

## 난무의 태도

완결편 무기 이름은 해독 1305개, 빈 이름 38개, 이름 셀 없음 64개다. 해독된 전체 이름에서 난무/태도/乱舞/太刀에 맞는 레코드는 식별하지 못했다. 사이버스터 #67의 원래 6개 무장은 #293 디스커터, #294 칼로릭미사일, #295 사이플래시(조건 81), #296 하이패밀리어, #297 아카식버스터, #298 코스모노바로 확인했다. 이름 없는 D_ANIME 동작까지 없다는 증거가 아니다.

## 미리보기 대용 가능성

미리보기의 세션 메모리에서만 다른 기존 투척 연출 선택자를 쓰는 별도 ‘대용 연출’ 기능은 설계할 수 있다. 다만 그 연출이 요구하는 기체 그림의 하위 파츠·무기 그림·명령 인자를 확인해야 하며, 단순히 창처럼 보이는 숫자를 넣는 것으로 안전성을 확인할 수 없다. 실제 ROM의 #874를 조용히 다른 무기로 바꾸거나 ‘롱기누스 원래 연출 복구’로 표시하지 않는다. 이번 작업에는 이 강제 대체를 추가하지 않았다.

다음으로 필요한 최소 근거는 원본 D_ANIME 리소스 로더의 정확한 선택자/자료 경계 해석과, 이름 없는 연출을 특정 기체·무기로 연결하는 참조다. 그 전에는 익명의 연출을 난무의 태도라고 등록하지 않는다.
