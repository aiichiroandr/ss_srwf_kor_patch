# SH-2 → WebAssembly 변환기 시제품

브라우저 안에서 사용자 디스크의 SH-2 기계어를 WebAssembly로 바로 바꾸는
방식([설계](../../docs/WEB_PORT_CLIENT_RECOMP.md))이 성립하는지 확인하기 위한
시제품입니다. 사이트 어디에서도 링크하지 않으며 게임을 실행하지 않습니다.

- **게임 내용 없음:** 게임 데이터, 게임 주소, 디스어셈블리는 없습니다. 테스트와
  벤치마크는 손으로 만든 합성 SH-2 코드만 씁니다.
- **`sh2.mjs`:** 명령 해석, 함수 범위 탐색, 전체 프로그램 참조 인터프리터. 기계
  모델은 saturn-recomp 런타임과 같습니다. 작업 RAM 두 개는 게스트 바이트 순서로
  두고, 그 밖의 주소는 입출력 콜백으로 보내며, SR은 필드별로 둡니다.
- **`emit.mjs`:** 함수 묶음을 WebAssembly 모듈 하나로 만듭니다.
  - 런타임의 호출 규약(CPU 상태 구조체 배치, `sh2_call`·`sh2_poll`·입출력·trap
    import, 호출 뒤 복귀 확인)을 따릅니다.
  - 리터럴 풀은 실행 중 메모리에서 읽으므로, 만들어진 모듈에는 원본 프로그램의
    데이터 바이트가 들어가지 않습니다.
- **`harness.mjs`:** 실제 런타임 대신 쓰는 JS 대역입니다. 처음 호출되는 주소를 그
  자리에서 번역하고, 안전 지점은 인터럽트처럼 문맥을 저장·뒤섞기·복원합니다.
- **`bench.mjs`:** `node lab/sh2-wasm/bench.mjs`로 직접 실행하는 측정 스크립트.
- **검증:** `tests/sh2-wasm.test.mjs`가 같은 프로그램을 인터프리터와 번역본으로
  실행해 레지스터, SR, GBR, MACH/MACL, PR, RAM, 입출력 기록을 비교합니다. 손으로 짠
  프로그램 8종과 무작위 다중 함수 프로그램 300개를 포함합니다.

지원 범위는 종료한 시험판 빌드가 번역했던 명령 형태 126종입니다. `rte`,
`sleep`, `braf`/`bsrf`, `cmp/str`, `addv`/`subv`, 지연 슬롯 안의 PC 상대 명령은
번역하지 않고 예외를 냅니다.
