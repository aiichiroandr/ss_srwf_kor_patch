# SH-2 → WebAssembly 변환기 시제품

브라우저 안에서 사용자 디스크의 SH-2 기계어를 WebAssembly로 바로 바꾸는
방식([설계](../../docs/WEB_PORT_CLIENT_RECOMP.md))이 성립하는지 확인하기 위한
시제품입니다. 사이트 어디에서도 링크하지 않으며 게임을 실행하지 않습니다.

- 게임 데이터, 게임 주소, 디스어셈블리는 없습니다. 테스트와 벤치마크는 손으로
  만든 합성 SH-2 코드만 씁니다.
- `sh2.mjs`: 명령어 해석, 함수 범위 탐색, 기준이 되는 참조 인터프리터.
- `emit.mjs`: 함수 하나를 WebAssembly 모듈 바이트로 만듭니다. 레지스터는 wasm
  지역 변수, 게스트 RAM은 32비트 단위 바이트 교환 배치, 리터럴 풀은 실행 중
  메모리에서 읽습니다. 따라서 만들어진 모듈에는 원본 프로그램의 데이터 바이트가
  들어가지 않습니다.
- `bench.mjs`: `node lab/sh2-wasm/bench.mjs`로 직접 실행하는 측정 스크립트.
- 검증: `tests/sh2-wasm.test.mjs`가 같은 프로그램을 인터프리터와 wasm으로 각각
  실행해 레지스터, T, PR, MACL, PC, RAM이 완전히 같은지 비교합니다. 무작위
  프로그램 300개를 포함합니다.

지원 범위는 제한적입니다. 자주 쓰는 정수·메모리·분기 명령과 지연 슬롯은
지원하지만, 다음은 아직 지원하지 않으며 만나면 예외를 냅니다.

- `braf`/`bsrf`, `mac`/`div` 계열, SR·GBR·VBR 조작, `trapa`, `sleep`
- 지연 슬롯 안의 PC 상대 명령
- MMIO, 인터럽트, 두 번째 CPU

모두 [설계](../../docs/WEB_PORT_CLIENT_RECOMP.md)의 후속 단계입니다.
