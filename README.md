# 슈퍼로봇대전 F 한국어 패치 — 로컬 배포 저장소

검증된 세가 새턴 원본 이미지에 한국어 패치를 적용하기 위한 정적 웹
도구와 공개 배포 메타데이터를 담는 저장소입니다. 패치는 사용자의
브라우저 안에서만 처리하며 원본 이미지를 서버로 전송하지 않습니다.

> **현재 상태: `HAS_ACCEPTED_RELEASE`**
>
> `Fable G25K 공개판`과 이전 `Fable G24 마이너 공개판` 두 항목이
> 명시적으로 승인되어 있습니다. G25K가 기본 선택이며 사용자는 리비전
> 목록에서 원하는 공개본으로 바꿀 수 있습니다.

## 지원 원본

현재 고정된 원본 프로필은 다음 하나뿐입니다.

- 크기: `578,512,032` bytes
- SHA-256: `c198a93007d46161abe769b6f579f01cae89e23737c0a2ff38ec314d43b3adf8`
- 형식: `TRACK 01 MODE1/2352`, `245,966` sectors

사용자는 위 값과 정확히 일치하는 본인 소유 원본 이미지를 선택해야
합니다. 저장소에는 원본, 완성 이미지, CUE, 게임 추출 파일, 세이브 또는
에뮬레이터 상태가 들어가지 않습니다.

브라우저 패처는 원본 전체 SHA-256과 변경 구간을 확인하면서 같은 한 번의
원본 읽기로 별도 IMG를 만듭니다. 원본이나 결과 검증이 하나라도 실패하면
임시 출력을 중단하며, 사용자가 선택한 파일에는 결과를 확정하지 않습니다.

## 로컬에서 확인하기

별도 패키지 설치나 외부 서비스가 필요하지 않습니다.

```bash
npm test
python3 -m http.server 8000
```

`npm test`가 패치 엔진, 공개 승격 검증기의 합성 회귀, 저장소 정책 검증을
모두 실행합니다.

그다음 `http://localhost:8000/`을 엽니다. 리비전 목록에
`Fable G25K 공개판`과 `Fable G24 마이너 공개판`이 표시되고, 정확한 원본
IMG를 선택할 수 있으면 정상입니다.

커밋 전 검증 훅은 이 저장소에만 다음처럼 연결할 수 있습니다. 훅은 네트워크
명령 없이 `npm test` 전체를 실행합니다.

```bash
git config core.hooksPath .githooks
```

## 공개 방식

공개 가능한 것은 명시적으로 `ACCEPTED` 처리된 릴리스의 희소 패치
파일(`.srwfp`)뿐입니다. 현재 G25K/G24 공개 인덱스, 릴리스 명세, 승인 영수증,
패치 본문은 모든 크기와 SHA-256이 서로 일치해야 합니다. 포맷은
[`docs/PATCH_FORMAT.md`](docs/PATCH_FORMAT.md), 승격 절차는
[`docs/RELEASE_POLICY.md`](docs/RELEASE_POLICY.md)에 고정되어 있습니다.

이 저장소는 지금 로컬에만 있으며 원격 저장소 생성, push, GitHub Pages
배포를 수행하지 않았습니다.

## 권리 고지

이 프로젝트는 비공식 팬 프로젝트이며 원 저작권자·플랫폼 사업자와
제휴하거나 승인을 받은 프로젝트가 아닙니다. 자세한 내용은
[`NOTICE.md`](NOTICE.md)를 확인하세요.
