# 세가 새턴 슈퍼로봇대전 F 한글 패치

세가 새턴판 **슈퍼로봇대전 F**와 **슈퍼로봇대전 F 완결편**의 한글 패치를
브라우저에서 적용하기 위한 정적 웹 패처입니다. 번역과 도구는
**Codex × Claude 협업**으로 제작하고 있습니다.

패처는 사용자가 직접 준비한 정품 디스크 이미지를 브라우저 안에서만 읽습니다.
원본을 서버에 올리지 않고, 원본과 다른 새 파일로 패치 결과를 만듭니다.

[GitHub Pages에서 패처 열기](https://aiichiroandr.github.io/ss_srwf_kor_patch/)

## 현재 공개 상태

| 게임 | 상태 | 현재 공개 버전 |
|---|---|---|
| 슈퍼로봇대전 F | 패치 가능 | **2026.08.12 · v1.1** |
| 슈퍼로봇대전 F 완결편 | 작업 중 | 공개 승인된 패치 없음 |

`v1.1`은 현재 기본 공개판입니다. 제작자 테스트 범위에서는
진행을 멈추게 하는 현상이 관찰되지 않았지만, 전체 경로 완주나 모든 화면의 완전한
번역을 뜻하지 않습니다. 대사 품질, 고유명사, 일부 UI 문구와 줄 배치는 계속 검수하고
솎아낼 예정입니다.

F 완결편은 구성요소 번역과 내부 검수가 진행 중이지만, 아직 공개용 전체 디스크 결과,
목표 SHA-256, 희소 패치와 공개 승인 영수증이 한 세트로 확정되지 않았습니다. 따라서
페이지에서는 게임을 고를 수 있지만 패치 실행은 `준비 중`으로 안전하게 잠깁니다.

## 버전별 패치 범위

웹 패처에서 버전을 고른 뒤 `패치노트 열기`를 누르면 대표 변경의 AS-IS/TO-BE를
바로 비교할 수 있습니다. `공개 릴리스 반영` 표시는 실제 공개 빌드에 들어간 변경이고,
`공개 릴리스 반영 · 기능 화면 참고` 표시는 같은 데이터·동작을 사용한 내부 기능
검증 화면으로 실제 반영 범위를 설명하는 비교입니다.
`RAM 변조 참고 시안` 표시는 후속 UI 배치를 검토하기 위한 참고 화면입니다.
RAM 시안은 현재 공개 릴리스의 반영·통과 증거가 아닙니다.

### 2026.08.12 · v1.1

현재 기본 선택 버전입니다. v1.0의 한글화 범위를 모두 포함하며 다음 화면을
추가로 보완하거나 다시 검증했습니다.

- `출격유닛 선택` 헤더 오른쪽의 동적 유닛 수(`NN기`) 위치 보정
- v1.0에서 이어지는 주인공 8명 이름과 출격 목록의 대표 기체·파일럿명
- 전투·대화 화면의 일부 화자명 여섯 항목
- 정신기 `사랑`, `봐주기` 표기와 연결 상태
- 턴 종료 문장, 질문창 문구와 프레임 배치
- F 완결편 예고 카드 다섯 장의 본문을 15포인트 기준으로 재배치
- 타이틀 메뉴 두 항목의 가운데 정렬과 간격

정확한 공개 결과 이미지는 자동 상태 불러오기 없이 4,800프레임을 실행해 타이틀과
`PRESS START` 표시, 정상 종료를 확인했습니다. 추가 기능 화면은 같은 변경 내용을 담은
내부 기능 검증본으로 두 차례, 합계 약 29분 관찰해 정상 종료를 확인했습니다. 이 기록은
전체 게임 완주나 장시간 무결성 보증이 아닙니다.

### 2026.08.10 · v1.0

현재 v1.1의 기반이 된 첫 공개 버전입니다. 다음 범위를 stock 기반으로 다시 조립해
공개했습니다.

- 시나리오 대사와 작전 목표, 전투 메시지의 한글 데이터
- 주인공 8명의 기본 이름·애칭과 출격 목록의 대표 기체·파일럿명
- 옵션, 개조, 파일럿, 음향 설정, 정신기 이름·커서·열 배치 등 주요 시스템 UI
- 저장 흐름과 일부 질문·선택·파츠 창 레이아웃
- 전투용 한글 그래픽과 시나리오 인물 식별 데이터
- F 완결편 예고 카드 일곱 장의 한국어 본문
- `이데배리어` 등 확인된 용어 표기

이 버전도 공개 결과의 콜드부트와 타이틀 도달을 확인했으며, 제작자가 관찰한 진행
구간에서는 멈춤이 보고되지 않았습니다. 이후 발견한 표기·배치 개선점은 v1.1 또는
[GitHub Issues](https://github.com/aiichiroandr/ss_srwf_kor_patch/issues)에서 추적합니다.

## 아직 남은 작업

- 일부 기체명, 인명, 고유명사와 목록 표기의 일본어·미정리 문자열
- 파일럿 풀네임의 띄어쓰기와 공유 문자열 분리 전수 검수
- 질문·선택·파츠 창의 폭과 줄바꿈
- 여러 경로의 대사 자연스러움과 용어 통일 재검수
- 정확한 공개 결과를 이용한 더 넓은 실플레이·장시간 회귀 확인

게임 화면에서 발견한 문제는 가능하면 `현재 화면(AS-IS)`, `원하는 화면(TO-BE)`,
재현 위치와 완료 판정을 함께 적어 이슈로 관리합니다. 패치노트에는 해당 UI를 설명하는
저해상도 비교 화면만 둘 수 있으며, 세이브, 상태 파일, 원본 또는 완성 디스크 이미지는
이슈나 저장소에 첨부하지 않습니다.

## 슈퍼로봇대전 F 지원 원본

현재 패치 가능한 원본 프로필은 세가 새턴 일본어판 F의 Track 01 이미지 하나입니다.

- 크기: `578,512,032` bytes
- SHA-256: `c198a93007d46161abe769b6f579f01cae89e23737c0a2ff38ec314d43b3adf8`
- 형식: `TRACK 01 MODE1/2352`, `245,966` sectors

위 값과 정확히 일치하는 본인 소유 원본을 선택해야 합니다. 파일명이 달라도 크기와
SHA-256이 같으면 되고, 이미지가 수정됐거나 다른 덤프이면 패처가 중단됩니다.

## 패치 방식

이 프로젝트는 xdelta가 아니라 자체 공개 포맷인 `.srwfp` 희소 바이트 패치를 씁니다.
패치 파일에는 바뀌는 바이트와 원본 구간 검증값만 들어 있으며 게임 전체 데이터는
들어 있지 않습니다.

브라우저는 다음 순서로 동작합니다.

1. 게임과 공개 버전을 선택합니다.
2. 정품 원본 IMG를 선택합니다.
3. `패치 시작`을 누르고 브라우저가 원본 위치에서 연 폴더 확인창을 승인합니다.
4. 패처가 그 폴더에 겹치지 않는 새 이름의 IMG를 만들고, 원본을 한 번 읽으면서
   전체 SHA-256과 각 변경 구간을 검증합니다.
5. 새 IMG의 전체 SHA-256까지 일치할 때만 저장을 확정합니다.

패처는 정품 원본 파일을 쓰기 대상으로 열지 않습니다. 출력에는 예측하기 어려운 고유
식별자가 붙은 새 이름을 사용해 기존 이름을 재사용하지 않습니다. F용 CUE도 패치 완료 뒤
패치 IMG와 같은 폴더에 만들 수 있습니다.

Android에서는 Chrome 132 이상, 데스크톱에서는 최신 Chrome 또는 Edge의 네이티브
파일 열기·폴더 저장 API를 사용합니다. 모바일 여부가 아니라 실제 API 지원 여부로 판정합니다.
iPhone·iPad Safari는 약 579 MB 결과를 사용자가 고른 Files 경로에 스트리밍 저장하는
동등한 API가 없어 현재 패치를 실행할 수 없습니다. 지원되지 않는 기기에서도 원본 선택
버튼을 누르면 필요한 환경을 화면에 안내합니다. 모바일에서 작업할 때는 패치가 끝날 때까지
화면을 켜 두고 다른 앱으로 전환하지 마세요.

## 로컬에서 확인하기

```bash
npm test
python3 -m http.server 8000
```

그다음 `http://localhost:8000/`을 엽니다. `슈퍼로봇대전 F`를 선택하면 두 공개
버전이 보이고, `F 완결편`을 선택하면 준비 중 안내와 잠긴 파일 선택 버튼이 보이면
정상입니다.

커밋 전 검증 훅은 다음처럼 이 저장소에만 연결할 수 있습니다.

```bash
git config core.hooksPath .githooks
```

## 공개 및 권리 고지

저장소에는 승인된 희소 패치와 정적 웹 파일, 패치 내역을 설명하는 저해상도 UI 비교
화면만 둡니다. 원본·완성 이미지, CUE, 추출 게임 파일, 세이브, 세이브 상태와
에뮬레이터 캐시는 배포하지 않습니다.

이 프로젝트는 비공식 팬 프로젝트이며 원 저작권자·플랫폼 사업자와 제휴하거나
승인을 받은 프로젝트가 아닙니다. 자세한 내용은 [NOTICE.md](NOTICE.md)를 확인하세요.
