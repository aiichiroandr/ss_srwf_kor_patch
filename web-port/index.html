백업 JSON은 웹 포트 전용 형식입니다. 웹 포트가 다시 열리면 그대로 복원할 수 있습니다.

선택한 게임의 저장만 담은 새 RAM 파일을 만듭니다. 에뮬레이터의 기존 RAM 파일을 그대로 덮어쓰면 다른 게임의 저장이 사라질 수 있으니 먼저 따로 보관하세요. 에뮬레이터 버전별 호환성은 모두 검증하지 못했습니다.

계속 플레이하려면

한글 패치 페이지에서 만든 BIN/CUE를 기기에 설치한 세가새턴 에뮬레이터로 실행하세요. 에뮬레이터는 이 프로젝트와 무관한 별도 프로그램이며, 게임 디스크와 BIOS는 직접 준비해야 합니다.

  • Windows · macOS · Linux: Ymir. Windows 10 이상, macOS 12 이상, 주요 리눅스 배포판용 공식 빌드가 있고 BIN+CUE를 읽습니다. 실행하려면 사용자가 가진 새턴 BIOS(IPL) 파일이 필요합니다. 내장 백업 메모리 관리자로 저장을 가져올 수 있습니다.
  • Android(갤럭시 등) · iPhone: Yaba Sanshiro 2가 Google Play와 App Store에 있습니다. 가격, 지원 기기, BIOS 필요 여부는 각 스토어 안내를 확인하세요.

위 목록은 2026년 11월 3일에 각 프로젝트 안내를 기준으로 정리했습니다. 이 패치와의 호환성을 에뮬레이터마다 보증하지는 않습니다.
