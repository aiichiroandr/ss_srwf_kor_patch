모바일 실행

MOBILE · 14

실행 중 음원 읽기 대기를 줄입니다. 시작 준비가 길어지고 디스크 크기만큼 메모리를 추가 사용합니다(최대 640MiB). 메모리가 8GB 이상으로 확인된 기기에서 기본으로 켭니다. 앱을 벗어나면 자동 일시정지하고 돌아오면 재개합니다.

소리 대기 목표를 약 0.06초로 줄이고 잔량에 맞춰 실행 타이밍을 조절합니다. 화면 프레임을 생략하지 않고 게임 로직과 음원 처리를 진행합니다. 2배속 처리가 계속 부족하면 자동으로 1배속으로 낮춥니다. 최적화를 끄고 다시 시작하면 기본 설정을 사용합니다.

맵 중단 저장은 타이틀의 이어하기로 불러오세요.

에뮬레이터 RAM 저장 가져오기·내보내기

표준 내부 RAM(.bkr/.srm/.bin)과 카트리지 RAM(.bcr)을 파일 내용으로 판별합니다. 순간저장·SSF 개별 저장·확장 내부 메모리는 아직 지원하지 않습니다. 카트리지에서 선택한 저장은 웹포트의 내부 메모리로 복사됩니다.

실행을 종료한 뒤 가져오기를 사용할 수 있습니다.

현재 게임의 저장으로 새 RAM 이미지를 만듭니다. 기존 에뮬레이터 RAM을 덮어쓰면 다른 게임 저장이 사라질 수 있으니 기존 파일을 보관하세요. 에뮬레이터 버전별 실제 호환 검증은 진행 중입니다.

백업 가져오기 및 복구

실행을 종료한 뒤 사용할 수 있습니다. 브라우저 데이터를 지우기 전에는 백업을 보관하세요.
