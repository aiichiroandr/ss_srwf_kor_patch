설명

파츠는 기체가 맵에 생성될 때 추첨됩니다. 이미 생성된 기체는 세이브에 정해진 보상을 유지할 수 있습니다.

설명

같은 지형 번호를 쓰는 모든 맵에 적용됩니다. 기체·무기의 지형 적응과는 별도입니다.

회피·방어 보정 30%는 해당 명중 계산값·피해에 70%를 곱합니다. 지형 효과를 받는 기체 상태에서 적용됩니다.

HP·EN 회복은 최대치의 비율입니다. 특수능력·기체 상태 등 다른 회복 요인에 따라 실제 회복량이 달라질 수 있습니다.

설명

데이터 번호는 시나리오 파일의 번호이며 게임의 몇 화인지를 뜻하지 않습니다. 같은 번호 묶음은 하나의 데이터를 공유합니다.

기체·이벤트 좌표·격추 보상·턴을 바꿉니다. 지원 사건은 페이즈와 최대 3개 조건을 조합합니다. 기존 대사·분기는 유지하며, 신규 증원은 검증 중입니다.

작전 목적 승리·패배마다 최대 3개 조건, 문구는 18자까지입니다. F는 현재 위치, 완결편은 지원 파일럿도 판정합니다. 기체 종류는 모든 진영을 합산합니다. 있음·없음은 현재 상태이며 격추·도착 이력이 아닙니다.

맵 선택한 BIN의 타일·기본 팔레트입니다. 점은 선택한 등장 묶음, 상태 1·2는 별도 맵 데이터입니다. 밤·날씨·애니메이션은 재현하지 않습니다. 타일을 바꾸면 공용 지형 효과도 바뀝니다.

저장 JSON은 편집값, BIN/CUE는 게임 적용용입니다. 압축 공간을 넘으면 저장을 중단합니다. 작전 목적을 바꿨다면 해당 전투에 들어가기 전의 게임 저장부터 진행해주세요.
